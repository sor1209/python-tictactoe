## About

A small Python project based on **Tic-Tac-Toe**, the familiar two-player game played on a 3 × 3 grid. Players take turns placing their marks and try to complete a row, column, or diagonal.

## Game concept

- Two players take alternating turns.
- The board contains nine positions.
- A player wins by completing three matching marks in a row, column, or diagonal.
- If all positions are filled without a winning line, the round ends in a draw.

## Technology

- Python 3

## Run locally

1. Clone this repository.
2. Make sure Python 3 is installed.
3. Open the project folder and run its main Python script:

```bash
python <entry-file>.py
```

Replace `<entry-file>.py` with the actual entry-point filename in the repository.
